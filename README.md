# Manneli ✨

**مانلی** — فروشگاه آنلاین لوازم و ملزومات ناخن

---

## درباره پروژه

مانلی یک فروشگاه آنلاین تخصصی لوازم و ملزومات ناخن (نیل آرت) است که سه بخش اصلی را در یک پلتفرم یکپارچه گرد هم آورده است:

### 🛒 فروشگاه
فروش مستقیم لوازم و محصولات ناخن برای علاقه‌مندان، متخصصان و کسب‌وکارهای نوین ناخن.

### 🎓 بخش آموزش (دوره‌های مدرسین)
مدرسین و اساتید حوزه‌ی ناخن می‌توانند **دوره‌های آموزشی خود را در پلتفرم ثبت و ارائه دهند** و به‌راحتی با شاگردان و هنرجویان ارتباط برقرار کنند.

### 🤝 ثبت نمایندگی
**نمایندگی‌ها و فروشگاه‌های فعال در این حوزه می‌توانند خود را در سایت ثبت کنند** و با پلتفرم و برند مانلی همکاری کنند.

---

## ساختار پروژه

این یک سایت **استاتیک خالص** است (بدون بیلد — بدون فریمورک و بدون مرحله‌ی کامپایل):

```
├── index.html          # صفحه اصلی سایت
├── css/
│   ├── base.css        # استایل‌های پایه و متغیرها
│   ├── layout.css      # چیدمان و گرید صفحه
│   ├── components.css  # استایل کامپوننت‌ها
│   └── overlays.css    # مودال‌ها و لوایه‌های متحرک
└── js/
    ├── main.js         # نقطه‌ی ورود اسکریپت‌ها
    ├── data.js         # داده‌های اولیه
    ├── catalog.js      # منطق کاتالوگ محصولات
    ├── cart.js         # سبد خرید
    ├── b2b.js          # بخش B2B (نمایندگی‌ها)
    ├── account.js      # حساب کاربری
    ├── ui.js           # ابزارهای رابط کاربری
    └── iran-map-data.js # داده‌ی نقشه‌ی ایران
```

---

## اجرا

سایت استاتیک است — فقط کافیست:

- `index.html` را مستقیم در مرورگر باز کنید، **یا**
- از هر سرور فایل استاتیک استفاده کنید:

```bash
# با هر کدام از این‌ها:
npx serve .
python -m http.server 8080
```
